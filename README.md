# 💛 Happy Friendship Day Surprise Website

A beautiful Friendship Day surprise website made with HTML, CSS and JavaScript.

## 📂 Project Structure

```
Friendship-Day/
│── index.html
│── style.css
│── script.js
│── photo.jpg
│── README.md
```

## 🚀 Features

- 💛 Yellow & Sky Blue Theme
- ❤️ Floating Hearts
- 🌸 Falling Flowers
- ✨ Twinkling Stars
- 💌 Emotional Messages
- 📸 Personal Photo
- 🎉 Final Friendship Day Surprise
- 📱 Mobile Responsive

## 🖼️ Add Your Photo

Place your photo in the project folder and rename it to:

```
photo.jpg
```

or update this line in `index.html`:

```html
<img src="your-photo-name.jpg" id="photo">
```

## ▶️ Run

Simply open:

```
index.html
```

in your browser.
